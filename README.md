# Расширение для браузера с использованием Gemini AI

Это расширение позволяет получать ответы от искусственного интеллекта **Gemini 2.5 Flash** прямо в браузере.

## Установка и настройка

1. **Добавьте API-ключи**  
   Откройте файл `background.js` и вставьте свои API-ключи от Gemini AI. Рекомендуется использовать **3 ключа или больше** для стабильной работы.

2. **Загрузите расширение в браузер**  
   - Перейдите в настройки расширений вашего браузера (например, в Chrome: `chrome://extensions/`)  
   - Включите режим разработчика  
   - Нажмите **Загрузить распакованное расширение** и выберите папку с расширением

3. **Перезагрузите сайты**, на которых хотите использовать скрипт, чтобы он начал корректно работать.

## Использование

- Для активации скрипта нажмите:  
  - **Windows/Linux:** `CTRL + SHIFT + Y`  
  - **Mac:** `CMD + SHIFT + Y`  
- Через несколько секунд в правом углу экрана появится ответ AI.  
  - Обратите внимание: окно ответа **не видно, пока не наведёте курсор**  
  - Текст отображается примерно **20 секунд** после появления

## Версия AI

- Используется **Gemini 2.5 Flash**
